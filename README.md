# 함께 발견하는 수학 · 빛의 실험실

브라우저에서 실행하는 한국어 교육 앱입니다. 외부 패키지나 빌드, API 키가 필요하지 않습니다.

## 실행

저장소 디렉터리에서 실행하세요.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저로 `index.html`(무게중심 구조대) 또는 `double-slit.html`(빛의 실험실)을 열면 됩니다. 두 페이지 사이의 링크로 이동할 수 있습니다. HTML 파일을 직접 열어도 실행됩니다.

## 영의 이중슬릿 실험

- **실험 상황:** 두 슬릿의 간섭, 한 슬릿의 회절, 위상 무관한 두 빛의 시간 평균 비교
- **조건 조절:** 파장 380–750 nm, 슬릿 간격 0.10–0.60 mm, 스크린 거리 0.50–3.00 m, 슬릿 너비 0.01–0.08 mm
- **과정 관찰:** 입사 → 슬릿 통과 → 중첩 → 무늬 관찰. 단계 선택, 일시정지, 한 단계 이동, 0.5/1/2배속, 초기화
- **빠른 실험:** 기본, 붉은 빛, 푸른 빛, 먼 스크린
- **3D 모델:** WebGL 기하 모델, 조건에 연동되는 슬릿·스크린과 간섭무늬, 드래그 회전, 휠 확대, 입체/위/정면 시점
- **접근성:** 키보드로 모든 설정 조작 가능. 3D 캔버스에 초점을 둔 뒤 방향키로 회전, `+`/`-`로 확대·축소. 모션 감소 설정에서는 일시정지로 시작
- **호환성:** WebGL을 사용할 수 없으면 Canvas의 3D 투영 도식으로 표시

균일한 슬릿에 단색광이 입사하는 원거리(Fraunhofer) 회절 모형을 사용합니다. `β = πa sinθ/λ`, `δ = πd sinθ/λ`일 때, 단일슬릿 밝기는 `sinc²β`, 위상 무관한 두 슬릿의 시간 평균은 `2 sinc²β`, 위상이 일치하는 두 슬릿은 `4 sinc²β cos²δ`입니다. `sinc(0) = 1`입니다.

그래프와 3D 스크린은 각각의 최댓값으로 정규화한 밝기를 ±15 mm 범위에 표시합니다. 비교 수치의 중앙 밝기는 같은 입사 세기의 한 슬릿을 기준으로 합니다. 무늬 간격 `Δy ≈ λL/d`와 단일슬릿 첫 최소 위치 `y₁ ≈ λL/a`는 작은 각도 근사입니다. 2D 파면, 장치 크기, 슬릿 모양과 시간은 관찰을 위한 모형이며 실제 축척이 아닙니다. 위상 무관 모드의 파면은 위상 변화의 예시이고 결과 그래프는 시간 평균입니다.

`slit-physics.js`는 공통 물리 계산, `slit.js`는 애니메이션과 WebGL 렌더링, `slit.css`는 실험실의 반응형 화면을 담당합니다. 실험실은 외부 리소스를 요청하지 않습니다.

## 무게중심 구조대

중학교 2학년 삼각형의 중선, 무게중심, 2:1 비율을 배우는 네 단계 퀴즈입니다. 귀여운 동물과 SVG 구조 지도를 사용하고 키보드로도 후보와 답을 선택할 수 있습니다. Google Fonts에 접근하지 못해도 시스템 글꼴로 실행됩니다.

## 검증

Node.js 18 이상에서 물리 계산 테스트를 실행할 수 있습니다. npm 설치는 필요하지 않습니다.

```sh
node --test tests/slit-physics.test.cjs
```

중앙 밝기, 보강·상쇄 조건, 무늬 간격, 단일슬릿 최소, 비간섭 밝기 합, 대칭성, 정규화 및 가시광 색을 검증합니다. 화면 검증 시에는 세 가지 실험 상황, 프리셋, 단계별 재생, 조건 변화에 따른 수치·무늬 변화, 3D 시점 조작과 작은 화면 레이아웃을 확인하세요.
